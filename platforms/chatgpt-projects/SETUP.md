# Setup: ChatGPT Projects

1. In ChatGPT, create a new Project (sidebar → **New project**), e.g. "SYNAPSE Intelligence Analysis".
2. Open the project's settings → **Instructions**, and paste the full contents of [`INSTRUCTIONS.md`](INSTRUCTIONS.md) (about 5,300 characters; the field holds up to 8,000).
3. Add these five files as project files (all from `synapse-intelligence-analysis/references/`):
   - `analyst.md`
   - `scenario.md`
   - `techniques.md`
   - `biases.md`
   - `estimative-language.md`
4. Optional: turn on web search in chats when the analysis needs current facts.
5. Start every analysis chat inside the project.

Five files fit within the Free plan's per-project file limit.

Example starters:
- "Analyze this situation using competing hypotheses, evidence, assumptions, and uncertainty."
- "Stress-test my current assessment: what biases, weak assumptions, or alternative explanations am I missing?"
- "Build 12-month scenarios from this situation with triggers, actor responses, and indicators to watch."
